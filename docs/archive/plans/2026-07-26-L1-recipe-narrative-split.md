# L1 — Recipe/narrative split Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every field exactly one writer by splitting the unified spec into a git-owned render recipe and a cloud-owned narrative (cached as a committed lockfile), then delete the merge algorithm that existed only because two writers shared one file.

**Architecture:** Introduce one composing loader — `scripts/ddd/spec_io.py::load_spec()` — that reads `<slug>.recipe.yaml` plus `<slug>.narrative.lock.json` and returns the same `UnifiedSpec` every consumer already expects. Route all eleven existing spec loaders through it. Then rewrite `narrative pull` to write the lockfile instead of merging into the spec, and delete `decide_narrative_sync`, `merge_narrative_into_spec`, `narrative_content_hash` and the `narrative_synced_*` fields.

**Tech Stack:** Python 3.12, Pydantic v2, pytest, PyYAML.

**Repos:** implementation in **`canopy`**. Task 9 migrates **`connect-labs`**. Plan and spec live in `canopy-web`.

**Spec:** `canopy-web/docs/superpowers/specs/2026-07-26-narrative-storyboard-and-ownership-design.md`, section "L1 — Split the document along the seam that already exists".

**Depends on:** L0 (`2026-07-26-L0-stable-scene-identity.md`) fully landed, including the Task 8 backfill. Scene ids are the key the two files are joined on; without them this plan has nothing to join.

## Global Constraints

- Work in a fresh git worktree off `origin/main` in the `canopy` repo. Never commit to `main` directly.
- Run tests from the canopy repo root: `uv run pytest tests/ddd/ -v`.
- **History is disposable.** Only the latest version of each narrative matters. The lockfile is justified by PR legibility and offline renders — *not* by reproducing old versions. Never add a compatibility shim to preserve a prior version; regenerate from the current one.
- **The composed `UnifiedSpec` is unchanged.** Every consumer keeps receiving the same object it does today. This plan changes where the bytes come from, not what the model looks like.
- One writer per field, enforced structurally:
  - `<slug>.recipe.yaml` — git. `show`, `url`, `viewport`, `full_page`, `pace`, `actions`, `design_intent`, `impressive_because`, `role`, `concept_claim`, plus spec-level `base_url`, `setup`, viewport defaults.
  - canopy-web — `name`, `narrative`, `personas`, `build_order`, and per-scene `title`, `persona`, `provenance`, `narrative`, `features`.
  - `<slug>.narrative.lock.json` — generated by `pull`, committed, **never hand-edited**.
- `concept_claim` is recipe-side (L0 established it has no cloud writer).
- Scene ids join the two files. A recipe scene with no matching lock scene is an error, not a silent empty.

```python
"""The ONE place a DDD spec is loaded from disk.

A narrative has two owners and therefore two files:

  ``<slug>.recipe.yaml``          git-owned. How to film it: selectors, URLs,
                                  viewports, actions, pacing, and the local
                                  falsifiable ``concept_claim``. This is code.
  ``<slug>.narrative.lock.json``  generated by ``narrative pull``, committed,
                                  NEVER hand-edited. A read-through cache of the
                                  cloud-owned story at a pinned version.

``compose`` joins them on the stable scene ``id`` (L0) and returns the same raw
spec dict every consumer has always parsed, so ``UnifiedSpec`` is unchanged.

Legacy single-file ``<slug>.yaml`` specs still load, unchanged, so this module
can be adopted call-site by call-site before anything is migrated.
"""
from __future__ import annotations

import json
from pathlib import Path

import yaml

from scripts.ddd.schemas.models import UnifiedSpec


class SpecCompositionError(Exception):
    """A recipe and a narrative lock that do not describe the same narrative."""


# Per-scene keys the LOCK owns. Everything else on a recipe scene is recipe.
_LOCK_SCENE_FIELDS = ("title", "persona", "provenance", "narrative", "features")
# Spec-level keys the LOCK owns.
_LOCK_TOP_FIELDS = ("name", "narrative", "personas", "build_order")


def recipe_path(base_dir, slug: str) -> Path:
    return Path(base_dir) / f"{slug}.recipe.yaml"


def lock_path(base_dir, slug: str) -> Path:
    return Path(base_dir) / f"{slug}.narrative.lock.json"


def compose(recipe: dict, lock: dict) -> dict:
    """Join a recipe and a narrative lock into a raw spec dict. Pure.

    Scene ORDER comes from the lock: the story owns the sequence, the recipe
    only says how to film each beat. Every scene must exist on both sides —
    a mismatch is a loud error, never a silently empty recipe (the failure
    mode the pre-L1 merge had).
    """
    recipe_scenes = {
        (s.get("id") or "").strip(): s
        for s in (recipe.get("scenes") or [])
        if isinstance(s, dict)
    }
    lock_scenes = [s for s in (lock.get("scenes") or []) if isinstance(s, dict)]
    lock_ids = [(s.get("id") or "").strip() for s in lock_scenes]

    missing = [sid for sid in lock_ids if sid not in recipe_scenes]
    if missing:
        raise SpecCompositionError(
            f"narrative lock has scene(s) with no recipe: {', '.join(missing)}. "
            f"Add them to the recipe (id + show) or re-pull the narrative."
        )
    orphans = sorted(set(recipe_scenes) - set(lock_ids))
    if orphans:
        raise SpecCompositionError(
            f"recipe has scene(s) absent from the narrative: {', '.join(orphans)}. "
            f"The story owns the scene list — delete them or add the beat on canopy-web."
        )

    scenes: list[dict] = []
    for ls in lock_scenes:
        sid = (ls.get("id") or "").strip()
        merged = dict(recipe_scenes[sid])
        merged.update({k: ls[k] for k in _LOCK_SCENE_FIELDS if k in ls})
        merged["id"] = sid
        scenes.append(merged)

    raw = {k: v for k, v in recipe.items() if k != "scenes"}
    raw.update({k: lock[k] for k in _LOCK_TOP_FIELDS if k in lock})
    raw["scenes"] = scenes
    return raw


def load_spec(path_or_slug, *, base_dir=None) -> UnifiedSpec:
    """Load a spec, composing recipe + lock when that's the shape on disk.

    Accepts a bare slug (with ``base_dir``), a ``<slug>.recipe.yaml`` path, or a
    legacy unified ``<slug>.yaml`` path. Returns a validated ``UnifiedSpec``.
    """
    p = Path(path_or_slug)
    if base_dir is not None and not p.suffix:
        slug, directory = str(path_or_slug), Path(base_dir)
    elif p.name.endswith(".recipe.yaml"):
        slug, directory = p.name[: -len(".recipe.yaml")], p.parent
    else:
        raw = yaml.safe_load(p.read_text()) or {}
        return UnifiedSpec.model_validate(raw)

    rpath, lpath = recipe_path(directory, slug), lock_path(directory, slug)
    if not lpath.exists():
        raise SpecCompositionError(
            f"no narrative lock at {lpath}. Run `python -m scripts.ddd.narrative "
            f"pull {slug}` to fetch the story from canopy-web."
        )
    recipe = yaml.safe_load(rpath.read_text()) or {}
    lock = json.loads(lpath.read_text())
    return UnifiedSpec.model_validate(compose(recipe, lock))
```

```python
def write_lock(base_dir, slug: str, version: int, parts: dict):
    """Write ``<slug>.narrative.lock.json`` — the committed read-through cache
    of the cloud-owned story at a pinned version.

    Generated, never hand-edited. Sorted keys + trailing newline so a re-pull of
    an unchanged version is a no-op in git rather than a diff.
    """
    from scripts.ddd.spec_io import lock_path

    payload = {
        "slug": slug,
        "version": version,
        "fetched_at": _now_iso(),
        "name": parts.get("name") or slug,
        "narrative": parts.get("narrative") or "",
        "personas": parts.get("personas") or {},
        "build_order": parts.get("build_order") or [],
        "scenes": [
            {
                "id": s["id"],
                "title": s.get("title", ""),
                "persona": s.get("persona", ""),
                "provenance": s.get("provenance", ""),
                "narrative": s.get("narrative", ""),
                "features": s.get("features") or [],
            }
            for s in (parts.get("scenes") or [])
        ],
    }
    p = lock_path(base_dir, slug)
    p.write_text(json.dumps(payload, indent=2, sort_keys=True, ensure_ascii=False) + "\n")
    return p
```

```python
"""One-shot: split a legacy unified spec into a recipe + a narrative lock.

Splits from the CURRENT on-disk spec, which is by definition the latest
version. Deliberately does NOT consult canopy-web or reconcile with any prior
version — per the design's standing constraint, history is disposable.

    python -m scripts.ddd.split_spec docs/walkthroughs/verified-monitoring.yaml
"""
from __future__ import annotations

import sys
from pathlib import Path

import yaml

from scripts.ddd.narrative import _scene_id, write_lock
from scripts.ddd.spec_io import recipe_path

_LOCK_SCENE_FIELDS = ("title", "persona", "provenance", "narrative", "features")
_LOCK_TOP_FIELDS = ("name", "narrative", "personas", "build_order")
_DEAD_TOP_FIELDS = (
    "narrative_synced_version", "narrative_synced_hash", "narrative_synced_at",
)


def split(spec_path) -> dict:
    """Write ``<slug>.recipe.yaml`` + ``<slug>.narrative.lock.json`` beside the spec."""
    p = Path(spec_path)
    slug = p.name[: -len(".yaml")] if p.name.endswith(".yaml") else p.stem
    raw = yaml.safe_load(p.read_text()) or {}
    scenes = [s for s in (raw.get("scenes") or []) if isinstance(s, dict)]

    lock_parts = {k: raw.get(k) for k in _LOCK_TOP_FIELDS}
    lock_parts["scenes"] = [
        {"id": _scene_id(s), **{k: s.get(k) for k in _LOCK_SCENE_FIELDS}}
        for s in scenes
    ]
    version = raw.get("narrative_synced_version") or 1
    lock = write_lock(p.parent, slug, version, lock_parts)

    recipe = {
        k: v for k, v in raw.items()
        if k not in _LOCK_TOP_FIELDS and k not in _DEAD_TOP_FIELDS and k != "scenes"
    }
    recipe["scenes"] = [
        {"id": _scene_id(s), **{k: v for k, v in s.items()
                                if k not in _LOCK_SCENE_FIELDS and k != "id"}}
        for s in scenes
    ]
    rpath = recipe_path(p.parent, slug)
    rpath.write_text(yaml.dump(recipe, default_flow_style=False,
                               allow_unicode=True, sort_keys=False))
    return {"recipe": rpath, "lock": lock}


def main(argv: list[str]) -> int:
    if not argv:
        print("usage: python -m scripts.ddd.split_spec <spec.yaml> [...]")
        return 2
    for arg in argv:
        out = split(arg)
        print(f"{arg} -> {out['recipe'].name} + {out['lock'].name}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main(sys.argv[1:]))
```

```python
"""CI gate: every recipe has a lock, they agree, and no lock was hand-edited.

Deliberately OFFLINE. Re-fetching from canopy-web would make CI fail whenever
the site is down, and would fail legitimately whenever someone pushes a new
narrative version before re-pulling. What must hold locally is structural:
the two files describe the same scene set, and the lock carries only story.

    python -m scripts.ddd.check_locks docs/walkthroughs
"""
from __future__ import annotations

import json
import sys
from pathlib import Path

import yaml

from scripts.ddd.spec_io import lock_path

_RECIPE_ONLY_FIELDS = (
    "show", "url", "viewport", "full_page", "pace", "actions",
    "design_intent", "impressive_because", "concept_claim", "role",
)
_REQUIRED_LOCK_KEYS = ("slug", "version", "fetched_at", "name", "narrative", "scenes")


def check(base_dir) -> list[str]:
    """Return a list of human-readable problems. Empty means clean."""
    base = Path(base_dir)
    problems: list[str] = []

    for rpath in sorted(base.glob("*.recipe.yaml")):
        slug = rpath.name[: -len(".recipe.yaml")]
        lpath = lock_path(base, slug)
        if not lpath.exists():
            problems.append(f"{slug}: recipe has no narrative lock — run `narrative pull {slug}`")
            continue

        recipe = yaml.safe_load(rpath.read_text()) or {}
        try:
            lock = json.loads(lpath.read_text())
        except json.JSONDecodeError as e:
            problems.append(f"{slug}: lock is not valid JSON ({e}) — it has been hand-edited")
            continue

        missing_keys = [k for k in _REQUIRED_LOCK_KEYS if k not in lock]
        if missing_keys:
            problems.append(
                f"{slug}: lock is missing generated key(s) {missing_keys} — hand-edited or stale"
            )

        recipe_ids = {(s.get("id") or "").strip() for s in (recipe.get("scenes") or [])}
        lock_scenes = lock.get("scenes") or []
        lock_ids = {(s.get("id") or "").strip() for s in lock_scenes}

        for sid in sorted(lock_ids - recipe_ids):
            problems.append(f"{slug}: lock scene {sid!r} has no recipe scene")
        for sid in sorted(recipe_ids - lock_ids):
            problems.append(f"{slug}: recipe scene {sid!r} is absent from the narrative")

        for s in lock_scenes:
            leaked = [f for f in _RECIPE_ONLY_FIELDS if f in s]
            if leaked:
                problems.append(
                    f"{slug}: lock scene {s.get('id')!r} carries recipe field(s) {leaked} "
                    f"— the lock has been hand-edited; re-pull it"
                )

    return problems


def main(argv: list[str]) -> int:
    base = argv[0] if argv else "docs/walkthroughs"
    problems = check(base)
    for p in problems:
        print(p)
    if problems:
        print(f"\n{len(problems)} problem(s). Locks are generated — re-pull, don't edit.")
        return 1
    print(f"{base}: locks clean")
    return 0


if __name__ == "__main__":
    raise SystemExit(main(sys.argv[1:]))
```
